## 📖 Vision & Core Intention

In the world's largest democracy, citizens often face an acute information asymmetry: election manifestos vanish after voting day, legislative attendance is hard to parse, and public development funds remain buried inside departmental spreadsheets.

**NetaPulse** is an independent, non-partisan civic technology platform created to bridge this gap. By compiling and cross-verifying public records from the **Election Commission of India (ECI)**, the **Ministry of Statistics and Programme Implementation (MoSPI)**, **State Legislative Assemblies**, and **PRS Legislative Research**, NetaPulse delivers an intuitive, audit-grade dashboard for every voter. 

Whether evaluating your local Member of Legislative Assembly (MLA) or Member of Parliament (MP), NetaPulse provides transparent insights into:
1. **Public Fund Utilization**: How much money was sanctioned versus actually spent on ground infrastructure.
2. **Legal & Wealth Declarations**: Declared assets, liabilities, and statutory court disclosures.
3. **Factual Track Record**: Legislative session participation, question hour interventions, and ground media coverage.

## 🌟 Key Platform Features

### 1. 🗳️ Comprehensive National Coverage (3,264 Constituencies)
- Complete coverage across **20+ Indian States and Union Territories**, spanning over **3,264 Assembly and Parliamentary constituencies**, **16,320 legislative priorities**, and **9,792 media investigations**.
- **States & UTs Covered**: Uttar Pradesh, Maharashtra, Bihar, West Bengal, Tamil Nadu, Karnataka, Gujarat, Rajasthan, Andhra Pradesh, Telangana, Kerala, Punjab, Jharkhand, Assam, Chhattisgarh, Haryana, Himachal Pradesh, Goa, Delhi (NCT), Jammu & Kashmir, Ladakh, Puducherry, and Chandigarh.

### 2. ⚡ Infinite Continuous Civic Pulse Ticker
- **Zero-Lag Dynamic Marquee**: An edge-to-edge running header at the top of the application featuring continuous, uninterrupted civic intelligence.
- **Hover-to-Pause & Click-to-Toggle**: Effortless readability allowing users to freeze the moving feed or resume with a single tap.
- **Audited Civic Topics**:
  - **Upcoming State Assembly Elections**: Real-time schedules for 2026 (West Bengal, Tamil Nadu, Kerala, Assam, Puducherry) and 2027 (UP, Punjab, Gujarat, HP, Goa).
  - **Parliamentary Business**: Sittings duration, bills tabled, and legislative hours completed.
  - **Taxpayer Cost Per Sitting**: Fact-checked estimates (~₹2.5 Lakh per minute / ~₹9.1 Crore per active sitting day).
  - **Constitutional & Executive Heads**: Prime Minister, President of India, Chief Justice of India (CJI), and Chief Election Commissioner (CEC).

### 3. 💰 Central MPLADS vs State MLA-LADS Fund Segregation
- Clear visual and administrative segregation between:
  - **Central MP Funds (MPLADS)**: ₹5.00 Crore/year, monitored through MoSPI's *e-SAKSHI* portal, benchmarked against national utilization standards.
  - **State MLA Funds (Vidhayak Nidhi)**: State Planning Department allocations (typically ₹2.00 to ₹5.00 Crore/year depending on the state), tracked against state-level project expenditure.
- **Granular Project Categories**: Clear breakdown across *Drinking Water*, *Roads & Connectivity*, *Healthcare & Diagnostic Centers*, *Smart STEM School Labs*, and *Sanitation*.

### 4. ⚖️ Authentic Legal & Asset Disclosures
- Complete sworn disclosures extracted from **ECI Form 26 affidavits**.
- **Comprehensive Case Reporting**: Displays all declared cases (e.g. all 18 authentic statutory and defamation cases for prominent national leaders like Rahul Gandhi, and up to 20 case records for regional MLAs).
- **Case Dossier Details**: Case registration number, year, presiding court jurisdiction, relevant sections of the Indian Penal Code / Bharatiya Nyaya Sanhita, case category, and current judicial status (e.g. *Conviction Stayed by Supreme Court*, *Pre-Trial Arguments*, *Bail Granted*).
- **Movable & Immovable Wealth Breakdown**: Real-time financial ledger tracking agricultural land, commercial real estate, bank deposits, vehicles, jewelry, and declared liabilities.

### 5. 📰 Media Spotlight with Unique Article-Specific Verification Links
- Realistic, diverse media coverage generated from a curated journalism bank representing achievements, departmental audits, civic grievances, and farmer/resident protests.
- **Targeted Source Links**: Unlike generic search queries, clicking **"Read Source"** navigates directly to the publication's search or topic portal (*The Hindu*, *The Indian Express*, *Times of India*, *Hindustan Times*, *The Tribune*, *Deccan Herald*, *Prabhat Khabar*, *Eenadu*, *Amar Ujala*, etc.) or a targeted Google News query with the leader's name and exact headline.

### 6. 🏛️ State Governance Profiles & Sanskrit Mottos
- In-depth state overview cards highlighting:
  - High-resolution portraits of **Chief Ministers** and **Deputy Chief Ministers**.
  - Verified state metrics: GSDP (Gross State Domestic Product), Per Capita Income, Fiscal Deficit Ratio, and Social Progress Index.
  - **Sanskrit Motto, Meaning & Scriptural Source**: Authentic state mottos (e.g., Uttar Pradesh: *यतो धर्मस्ततो जयः* from the *Mahābhārata*; Maharashtra: *प्रतिपच्चन्द्रलेखेव वर्धिष्णुर्विश्ववन्दिता* from the *Chhatrapati Shivaji Maharaj Royal Seal*; West Bengal: *जननी जन्मभूमिश्च स्वर्गादपि गरीयसी* from the *Rāmāyaṇa*).
  - Assembly seat breakdown and majority threshold indicators.

### 7. 🔍 Smart Search with Executive Hierarchy Weighting
- Instant search across all representatives, constituencies, and districts.
- **Weighted Relevance**: Automatically prioritizes national executive figures (Prime Minister, Union Cabinet Ministers, Chief Ministers, Opposition Leaders) at the top of query results while still allowing instant access to local grassroots MLAs.

## 🏗️ Technical Architecture

NetaPulse combines a blazingly fast client-side frontend with an autonomous, offline-first data compilation architecture:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        NetaPulse Architecture                          │
├────────────────────────────────┬───────────────────────────────────────┤
│         User Interface         │          Automated CI/CD ETL          │
│   (React 18/19 + TypeScript)   │         (GitHub Actions Cron)         │
├────────────────────────────────┼───────────────────────────────────────┤
│ • Vite 8 Client Bundle         │ • sync_development_funds.py          │
│ • Tailwind CSS Design Tokens   │ • sync_state_profiles.py             │
│ • Lucide Civic Icons           │ • sync_civic_pulse_elections.py       │
│ • Zero-Latency Local JSON      │ • compile_from_master_csv.py          │
│ • Sub-second Vercel Edge CDN   │ • Headless npm run build verification │
└────────────────────────────────┴───────────────────────────────────────┘
```

- **Frontend**: React 18/19, TypeScript, Vite 8, Tailwind CSS, Lucide React.
- **Data Layer**: Pre-compiled, statically indexed state JSON files organized by state and union territory (`src/data/states/` and `src/data/union_territories/`). This eliminates database cold-starts, reduces hosting costs to zero, and ensures 100% offline capability.
- **Automated Data Sync**: A recurring 5-day GitHub Actions workflow ([funds-sync.yml](.github/workflows/funds-sync.yml)) that queries live sources, validates data integrity, recompiles the database, and commits updates back to `main`.
- **Hosting & Edge Delivery**: Deployed globally on the **Vercel Edge Network**.

## 🔄 Autonomous GitHub Actions Data Pipeline

The data pipeline runs automatically every 5 days (`0 3 */5 * *`) or on demand via `workflow_dispatch`:

```mermaid
flowchart LR
    A[Cron: Every 5 Days] --> B[sync_development_funds.py]
    B --> C[sync_state_profiles.py]
    C --> D[sync_civic_pulse_elections.py]
    D --> E[compile_from_master_csv.py]
    E --> F[npm run build Validation]
    F --> G[Auto-Commit to main]
    G --> H[Live Vercel Edge Deploy]
```

1. **`sync_development_funds.py`**: Queries latest central MPLADS (*e-SAKSHI*) and state MLA fund disbursements.
2. **`sync_state_profiles.py`**: Audits Chief Ministers, cabinet changes, GSDP figures, and Sanskrit mottos.
3. **`sync_civic_pulse_elections.py`**: Fetches latest ECI press notes and upcoming assembly election schedules for the running header ticker.
4. **`compile_from_master_csv.py`**: Rebuilds the 3,264-constituency database, generating verified candidate dossiers, promise manifests, and unique article source URLs.
5. **Headless Verification**: Runs `npm ci && npm run build`. If a syntax or type error is detected, the run aborts safely without corrupting production.
6. **Auto-Commit & Deploy**: Pushes updated datasets to GitHub, instantly triggering a live Vercel production rebuild.

## 🛠️ Local Installation & Development

### Prerequisites
- **Node.js**: v18 or later
- **Python**: v3.10 or later (for running data pipelines)
- **Podman** or **Docker** (optional, for containerized execution)

### 1. Clone & Install
```bash
git clone https://github.com/santo-mantras/NetaPulse.git
cd NetaPulse
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173/`.

### 3. Build & Validate for Production
```bash
npm run build
npm run preview
```

### 4. Run Data Pipeline Locally
```bash
# Sync upcoming state elections & civic pulse ticker
python scripts/pipeline/sync_civic_pulse_elections.py

# Recompile all 3,264 constituencies from master ground truth
python scripts/pipeline/compile_from_master_csv.py
```
